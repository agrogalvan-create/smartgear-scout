# Google Search Console — SmartGear Scout

## Property

Choose **URL prefix** (not Domain), and enter:

https://agrogalvan-create.github.io/smartgear-scout/

Use the exact trailing slash. This is a project site under a shared github.io domain, so verifying the entire domain is not appropriate.

## Verify ownership

Select the **HTML file** verification method. Download the file from Search Console. Upload that **exact file, unchanged**, to the root of this GitHub repository. Wait for GitHub Pages deployment, open the verification URL, then click Verify in Search Console.

Do not upload account credentials or tokens to the repository.

## Sitemap

After verification, in Search Console → Sitemaps, submit:

sitemap.xml

Full address:
https://agrogalvan-create.github.io/smartgear-scout/sitemap.xml

## Weekly monitoring

Record: search impressions, clicks, CTR, average position, indexed pages, top queries, outbound merchant clicks, approved affiliate orders and earned commissions. Avoid treating impressions as sales.

## Notes

Search Console verification and indexing require action by the site owner; adding a sitemap does not guarantee indexing or traffic. GitHub Pages is public and repository files are publicly visible.
